# LinkedIn media studio

Renders Christophe Atten's LinkedIn visuals from a JSON spec, in the same design as the posts
already scheduled: images (JPG), carousels (PDF plus a cover JPG) and short kinetic videos (MP4
with a synthesised backing track).

Requirements: Python 3, Playwright with Chromium, Pillow, numpy, scipy, img2pdf, ffmpeg.
Missing Python packages: `pip install --break-system-packages img2pdf numpy scipy pillow`.
If `ffmpeg` is not on the PATH, the studio installs `imageio-ffmpeg` and uses its binary.

```
python3 studio.py image    spec.json --out OUT --name BASE   # OUT/BASE.jpg (2160x2700)
python3 studio.py carousel spec.json --out OUT --name BASE   # OUT/BASE.pdf, OUT/BASE_cover.jpg
python3 studio.py video    spec.json --out OUT --name BASE   # OUT/BASE.mp4, OUT/BASE_poster.jpg
```

Every run also writes `OUT/BASE_check.jpg`, a contact sheet of the pages or of the last frame of
every video scene. Look at it before using the result. The command prints a JSON report.
Exit code 2 means the files were written but some text overflows: shorten it and render again.
A video takes about two minutes to render for 50 seconds of footage.

## Content rules (always)

- British English. No em dashes or en dashes anywhere: use commas, colons or full stops.
- No brand logos and no company names in the visuals, except a company the post itself is about.
- Never mention Christophe's employer or any bank he may work for.
- No invented numbers: every figure must come from the post text or a source it cites.
- Short lines. A slide or scene should be readable in a few seconds.

## Image spec

```json
{
  "eyebrow": "Identify · From practice",
  "title": "Build, buy, partner or skip?",
  "grid": [["Buy", "General task, everyday productivity"], ["Partner", "..."], ["Build", "..."], ["Skip", "..."]],
  "kicker": "Decide before momentum decides for you.",
  "badge": "Free tool: link in the post"
}
```

Use exactly one of `items` (list of `[title, detail]`, up to 10), `grid` (four `[title, detail]`
cells) or `twocol` (`[[left items], [right items]]`, optional `"labels": ["Handles well", "Never owns"]`).
`kicker` and `badge` are optional. See `examples/image.json`.

## Carousel spec

`{"slides": [ ... ]}`, 5 to 10 slides. Slide kinds:

| kind  | fields |
|-------|--------|
| cover | eyebrow, title, sub |
| step  | n (e.g. "01"), title, body, tip (optional) |
| plain | eyebrow, title, body, tip (optional) |
| list  | eyebrow, title, items (up to 7), start (optional number) |
| rule  | eyebrow (optional), title, body |
| cta   | eyebrow (optional), title, body, sub |

Start with a `cover`, end with a `cta` that points to the link in the post (the arrow points up).
The PDF's document title in Buffer is the cover title. See `examples/carousel.json`.

## Video spec

```json
{"music": true, "bpm": 112, "scenes": [ ... ]}
```

1080x1350, 30 fps, about 6 seconds per scene, 6 to 9 scenes. Backgrounds (`bg`): navy, navy2,
teal, red, paper, yellow. Alternate backgrounds so every scene feels like a cut. Scene kinds:

| kind      | fields |
|-----------|--------|
| number    | kicker, value (number, counts up), format (comma, int, dec1, pct), prefix, suffix, caption |
| statement | lines (1 to 3 short lines, shown in capitals), highlight (big last word), sub, deco (true) |
| maths     | kicker, lines (2 to 4), result (shown in a band), note |
| cards     | kicker, items [{label, value, tone: red, teal or yellow}], note |
| versus    | top, bottom (with a drawn "not equal" sign between), sub, pills, note |
| pills     | kicker, title, sub, pills, note |
| strike    | pre, struck (gets crossed out), post, big, note |
| metric    | counter ("Metric 1/3"), dots [current, total], title, text, bars [{label, value 0 to 1, tone}], note |
| grid      | title, text, cells (50), marked (indexes in red), legend [two labels], note |
| list      | kicker, title, items (up to 5) |
| big       | kicker, text, sub, size (big, huge, mid) |
| end       | variant "book" (book cover and christopheatten.com/book) or "follow" (title, sub, url) |
| html      | html (your own markup), words (reading length), reveal (seconds until fully shown) |

Any scene takes `dur` (seconds) to override the automatic timing. In `html` scenes, animate
elements with `data-anim` (up, down, left, right, fade, pop, zoom, wipe, count, strike, grow,
type, slide), `data-at` (seconds after the scene starts) and `data-len` (duration). The engine
also exposes CSS classes: kick, lead, mega, huge, big, mid, text, note, band, pill, pills,
card, cards, list, li, and the colours c-yellow, c-teal, c-red, c-white, c-navy.
See `examples/video.json`.

The soundtrack is generated by `music.py` (no samples, no licensing). Set `"music": false` for
a silent track.
